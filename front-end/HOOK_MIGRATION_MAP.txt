grep -r "from.*hooks/" src --include="*.tsx" --include="*.ts"

grep -r "useOldHookName" src --include="*.tsx" --include="*.ts"

================================================================================
📝 NOTES IMPORTANTES
================================================================================

1. Le schéma GraphQL est dans: api/src/graphql/schema.ts
2. Les TypeDefs modulaires sont dans: packages/types/src/domains/
3. Hooks auto-générés: front-end/src/lib/apollo/generated/graphql.ts
4. Opérations GraphQL: front-end/src/graphql/queries/*.graphql

5. TOUJOURS regénérer les types après modification du schéma:
   cd front-end && npm run codegen

6. Les hooks wrapper sont facultatifs - vous pouvez utiliser les hooks
   auto-générés directement dans vos composants

7. Apollo Client gère automatiquement:
   - Le cache
   - L'authentification (via authLink)
   - Les erreurs (via errorLink)
   - Le loading state

================================================================================
🚀 PROCHAINE ÉTAPE
================================================================================

1. Choisir un module à migrer complètement
2. Créer les queries/mutations manquantes dans le schéma
3. Régénérer les types (npm run codegen)
4. Créer les hooks wrapper si nécessaire
5. Mettre à jour les imports dans les composants
6. Tester
7. Supprimer l'ancien hook REST
