Exemple d'implémentation sans backend :

export const useCommandesStats = () => {
  const { orders, isLoading } = useOrders();

  const stats = useMemo(() => {
    const totalOrders = orders.length;
    const pendingOrders = orders.filter(o => o.status === 'pending').length;
    const completedOrders = orders.filter(o => o.status === 'completed').length;
    const totalRevenue = orders
      .filter(o => o.status === 'completed')
      .reduce((sum, o) => sum + (o.total_amount || 0), 0);
    const averageOrderValue = completedOrders > 0 ? totalRevenue / completedOrders : 0;

    return {
      totalOrders,
      pendingOrders,
      completedOrders,
      totalRevenue,
      averageOrderValue,
    };
  }, [orders]);

  return { ...stats, isLoading, error: null };
};

CONVENTIONS DE NOMMAGE
----------------------

Fichiers GraphQL :
  - Queries : Get*.graphql (ex: GetInstructors.graphql)
  - Mutations : Create*.graphql, Update*.graphql, Delete*.graphql
  - Localisation : src/features/[feature]/api/graphql/

Hooks générés :
  - Queries : use[Name]Query (ex: useGetInstructorsQuery)
  - Mutations : use[Name]Mutation (ex: useCreateInstructorMutation)

GESTION D'ERREURS
-----------------

Toujours inclure :

try {
  const result = await mutation({ variables: { input } });
  console.log('Success:', result.data);
  return result.data;
} catch (err) {
  console.error('Error:', err);
  throw err;
}
