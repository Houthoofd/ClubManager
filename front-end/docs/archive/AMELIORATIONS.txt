🟠 PRIORITE 2 - STATE MANAGEMENT (Semaine 3-4)
================================================================================

Problème:
- Redux commenté mais non supprimé
- État auth dispersé (localStorage + Apollo + useState)
- Pas de source unique de vérité
- Code difficile à maintenir

Solution: ZUSTAND + Apollo Client

Pourquoi Zustand?
✅ 90% moins de boilerplate que Redux
✅ 1KB vs 20KB (Redux + Redux Toolkit)
✅ TypeScript natif avec inférence automatique
✅ Redux DevTools intégrés
✅ Middleware persist (localStorage automatique)
✅ Pas de Provider nécessaire

Architecture proposée:

  SERVER STATE (Apollo Client Cache)
  ├─ Queries/Mutations GraphQL
  ├─ Cache normalisé
  └─ Optimistic updates

  GLOBAL CLIENT STATE (Zustand)
  ├─ Authentication (token, user, isAuth)
  ├─ Shopping cart (items, total)
  ├─ UI preferences (theme, language)
  └─ Notifications queue

  LOCAL UI STATE (useState/useReducer)
  ├─ Form inputs
  ├─ Modal open/close
  └─ Temporary selections

Installation:
  npm install zustand immer

Exemple store (src/store/index.ts):

  import { create } from 'zustand';
  import { persist, devtools } from 'zustand/middleware';

  export const useStore = create(
    persist(
      devtools((set) => ({
        // Auth
        auth: { token: null, user: null, isAuthenticated: false },
        login: (token, user) =>
          set({ auth: { token, user, isAuthenticated: true } }),
        logout: () =>
          set({ auth: { token: null, user: null, isAuthenticated: false } }),

        // Cart
        cart: { items: [], total: 0 },
        addToCart: (item) => set(state => ({
          cart: {
            items: [...state.cart.items, item],
            total: state.cart.total + item.price
          }
        })),
        clearCart: () => set({ cart: { items: [], total: 0 } }),
      })),
      { name: 'clubmanager-storage' }
    )
  );

Migration:
  AVANT:
    const token = localStorage.getItem('authToken');
    const userData = JSON.parse(localStorage.getItem('userData') || '{}');

  APRES:
    import { useStore } from '@/store';
    const { user, token, isAuthenticated } = useStore(state => state.auth);
    const login = useStore(state => state.login);

Avantages:
- Persistence automatique
- Undo/Redo facile
- Time-travel debugging
- Tests plus simples
- Performance optimale (sélecteurs)

     return result.data.order;

🟢 PRIORITE 4 - ERROR HANDLING (Semaine 6)
================================================================================

Problème:
- Erreurs seulement dans console
- Utilisateurs ne voient rien
- Pas de retry mechanism
- Messages techniques (pas user-friendly)

Solution: Error Handler Centralisé + Toast Notifications

Installation:
  npm install react-hot-toast

Créer: src/core/errors/errorHandler.ts

  import toast from 'react-hot-toast';
  import { ApolloError } from '@apollo/client';

  export class AppError extends Error {
    constructor(
      message: string,
      public code: string,
      public severity: 'error' | 'warning' | 'info' = 'error'
    ) {
      super(message);
      this.name = 'AppError';
    }
  }

  export const handleError = (error: unknown): AppError => {
    if (error instanceof ApolloError) {
      if (error.networkError) {
        return new AppError(
          'Connexion au serveur impossible. Vérifiez votre connexion.',
          'NETWORK_ERROR',
          'error'
        );
      }
      if (error.graphQLErrors.length > 0) {
        return new AppError(
          error.graphQLErrors[0].message,
          'GRAPHQL_ERROR',
          'error'
        );
      }
    }

    return new AppError(
      error instanceof Error ? error.message : 'Erreur inconnue',
      'UNKNOWN_ERROR',
      'error'
    );
  };

  export const showError = (error: unknown) => {
    const appError = handleError(error);
    toast.error(appError.message, { duration: 5000 });
    console.error(`[${appError.code}]`, appError);
  };

Utilisation:

  const LoginPage = () => {
    const [login, { loading }] = useLoginMutation();

    const handleLogin = async (data: FormData) => {
      try {
        const result = await login({ variables: data });
        if (result.data?.login) {
          toast.success('Connexion réussie !');
          navigate('/dashboard');
        }
      } catch (error) {
        showError(error); // Centralisé !
      }
    };

    return <LoginForm onSubmit={handleLogin} />;
  };

Error Boundary: ✅ Déjà implémenté (ErrorBoundary.tsx)
