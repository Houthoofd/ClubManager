================================================================================
INSTRUCTIONS - SETUP BASE DE DONNÉES DE TEST
================================================================================

Ce dossier contient les scripts pour initialiser et maintenir la base de
données de test `clubmanager_test` avec les données de référence nécessaires
pour les tests d'intégration réels du module d'inscription.

================================================================================
FICHIERS DISPONIBLES
================================================================================

1. setup-test-db.cjs
   - Vérification intelligente de la DB
   - Insertion sélective (seulement ce qui manque)
   - Idempotent (safe à exécuter plusieurs fois)
   - RECOMMANDÉ pour usage quotidien

2. seed-test-db.cjs
   - Seed complet et forcé
   - Vide et réinsère tout (TRUNCATE)
   - Utiliser pour réinitialisation complète

3. seed-test-db.sql
   - Script SQL brut
   - Pour exécution manuelle via mysql CLI
   - Même fonction que seed-test-db.cjs

4. RESULTS.txt
   - Résumé des résultats de tests
   - Analyse des problèmes résolus/restants

================================================================================
PRÉREQUIS
================================================================================

1. MySQL Server en cours d'exécution
2. Base de données `clubmanager_test` créée
3. Fichier .env.test configuré dans ClubManager/api/

Variables requises dans .env.test:
  DB_HOST=localhost
  DB_PORT=3306
  DB_USER=root
  DB_PASSWORD=votre_mot_de_passe
  DB_NAME=clubmanager_test
  DATABASE_URL=mysql://root:password@localhost:3306/clubmanager_test

================================================================================
UTILISATION RAPIDE
================================================================================

## Méthode 1: Via npm (RECOMMANDÉ)

# Depuis le dossier ClubManager/api/
npm run setup:test:db

# Ou depuis la racine ClubManager/
npm run setup:test:db

## Méthode 2: Node direct

# Depuis le dossier ClubManager/api/
node scripts/seed/setup-test-db.cjs

## Méthode 3: SQL direct

# Depuis n'importe où
mysql -u root -p clubmanager_test < ClubManager/api/scripts/seed/seed-test-db.sql

================================================================================
COMMANDES NPM DISPONIBLES
================================================================================

Depuis ClubManager/api/:

  npm run setup:test:db
    → Vérifie la DB et insère seulement ce qui manque
    → Idempotent, safe, rapide
    → À UTILISER AVANT LES TESTS

  npm run seed:test:db
    → Réinitialisation complète (TRUNCATE + INSERT)
    → À utiliser si vous voulez repartir de zéro

  npm run clean:test:users
    → Supprime les utilisateurs de test créés pendant les tests
    → Nettoie les emails contenant "test-real-db" ou "test-inscription"

  npm run test:inscription:integration:real
    → Exécute automatiquement setup:test:db puis lance les tests
    → C'est la commande à utiliser pour tester !

================================================================================
DÉPANNAGE
================================================================================

Problème: "Error: Cannot find module 'mysql2/promise'"
Solution:
  cd ClubManager/api
  npm install

Problème: "ECONNREFUSED"
Solution:
  - Vérifier que MySQL est démarré
  - Vérifier host/port dans .env.test

Problème: "ER_BAD_DB_ERROR"
Solution:
  - Créer la base de données:
    mysql -u root -p
    CREATE DATABASE clubmanager_test;
    exit

Problème: "Access denied for user"
Solution:
  - Vérifier DB_USER et DB_PASSWORD dans .env.test
  - Vérifier les permissions MySQL:
    GRANT ALL ON clubmanager_test.* TO 'root'@'localhost';

Problème: Tests échouent avec "ER_NO_REFERENCED_ROW_2"
Solution:
  - Relancer setup:test:db
  - Les données de référence sont manquantes

Problème: Le script dit "Fichier .env.test non trouvé"
Solution:
  - Créer .env.test dans ClubManager/api/
  - Copier depuis .env.test.COMPLET ou .env.test.backup
  - Ou définir les variables d'environnement système

================================================================================
INTÉGRATION CI/CD
================================================================================

Pour GitHub Actions / GitLab CI:

1. Ajouter dans le pipeline avant les tests:

   - name: Setup test database
     run: |
       cd api
       npm run setup:test:db

2. Variables d'environnement CI:

   DB_HOST: localhost
   DB_PORT: 3306
   DB_USER: root
   DB_PASSWORD: ${{ secrets.DB_TEST_PASSWORD }}
   DB_NAME: clubmanager_test

3. Service MySQL dans CI:

   services:
     mysql:
       image: mysql:8.0
       env:
         MYSQL_ROOT_PASSWORD: test_password
         MYSQL_DATABASE: clubmanager_test
       ports:
         - 3306:3306

================================================================================
MAINTENANCE
================================================================================

Ajouter de nouvelles données de référence:

1. Éditer setup-test-db.cjs:
   - Ajouter dans REQUIRED_DATA{}
   - Spécifier table, requiredIds, data

2. Éditer seed-test-db.cjs:
   - Ajouter dans seedData{}
   - Ajouter l'appel dans main()

3. Éditer seed-test-db.sql:
   - Ajouter section avec INSERT

4. Tester:
   npm run seed:test:db

SUPPORT
================================================================================

En cas de problème:

1. Vérifier les logs du script (très verbeux)
2. Consulter RESULTS.txt pour l'état actuel
3. Vérifier manuellement la DB avec mysql CLI
4. Relancer avec seed complet: npm run seed:test:db

Les scripts sont conçus pour être:
  ✓ Idempotents (safe à réexécuter)
  ✓ Verbeux (affichent ce qu'ils font)
  ✓ Résilients (gèrent les erreurs)
  ✓ Rapides (< 1 seconde)
