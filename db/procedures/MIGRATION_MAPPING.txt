⚠️ NOTES DE MIGRATION
================================================================================

BREAKING CHANGES:
-----------------
Aucun! Tous les alias de compatibilité sont créés.

CHANGEMENTS SIGNATURE:
----------------------
1. create_recurring_course_with_teachers()
   - Nouveaux paramètres: p_sport_id, p_course_type_id, p_capacity, p_location
   - Nouveaux OUT: p_success, p_message, p_courses_created
   - Compatible via alias avec ancienne signature

2. update_recurring_course_with_teachers()
   - Nouveau paramètre: p_update_future_courses (BOOLEAN)
   - Permet de MAJ les cours futurs automatiquement

3. get_user_attendance_statistics()
   - Nouveaux paramètres: p_sport_id, p_start_date, p_end_date
   - Retourne plusieurs resultsets (overview, by_month, by_sport, trend)

RECOMMANDATIONS:
----------------
1. Tester sur environnement de développement d'abord
2. Backup base de données avant migration production
3. Mettre à jour code applicatif pour utiliser nouvelles procédures
4. Garder les alias pendant période de transition (3-6 mois)
5. Supprimer les alias après migration code applicatif complète
