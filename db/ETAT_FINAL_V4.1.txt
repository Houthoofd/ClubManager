SOFT DELETE + ANONYMISATION (v4.1)
  • Colonnes : deleted_at, deleted_by, deletion_reason, anonymized
  • Procédure : safe_delete_user(user_id, admin_id, reason)
  • Résultat : Données perso anonymisées + historique comptable préservé
  • Restauration : Possible AVANT anonymisation (protection erreurs)

DONNÉES ANONYMISÉES :
  first_name → ANONYME_{id}
  last_name → SUPPRIME
  email → deleted_{id}@anonymized.local
  telephone → NULL
  adresse → NULL
  photo_url → NULL

DONNÉES PRÉSERVÉES (obligations comptables) :
  ✅ id (lien paiements)
  ✅ Historique paiements (7-10 ans)
  ✅ Historique inscriptions
