   - Invalid input handling
   - Edge cases
   - Type safety

4. **Stores** : 5 tests minimum
   - Initial state
   - State updates
   - Async actions
   - Error handling
   - Persistence (if applicable)

### **9. Apollo Cache - TypePolicies (Priorité 9) 🚀**

**État actuel** :
- ✅ Cache persistence (localStorage)
- ✅ Error handling complet
- ✅ Cache metadata (version, timestamp, size)
- ⚠️ Pas de typePolicies pour pagination/merge

**À ajouter dans apollo-client.ts** :
```typescript
const cache = new InMemoryCache({
  typePolicies: {
    Query: {
      fields: {
        // Pagination offset-based
        users: {
          keyArgs: ['filter', 'search'],
          merge(existing = [], incoming, { args }) {
            const offset = args?.offset || 0;
            const merged = existing ? existing.slice(0) : [];
            for (let i = 0; i < incoming.length; ++i) {
              merged[offset + i] = incoming[i];
            }
            return merged;
          },
        },
        // Pagination cursor-based
        orders: {
          keyArgs: ['filter'],
          merge(existing, incoming, { args }) {
            if (!existing) return incoming;
            if (!args?.after) return incoming;
            return {
              ...incoming,
              edges: [...existing.edges, ...incoming.edges],
            };
          },
        },
      },
    },
  },
});
```
